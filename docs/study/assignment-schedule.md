# Assignment schedule (V3)

**V3 changes the treatment (agent-guided MacroTable), so these codes replace the V2 `T…`/`P…` codes.** Never pool V2 and V3 observations.

Counterbalanced within-participant design (protocol §5). Scenario order is fixed (Task 1 = **A**, Task 2 = **B**), and the **condition order alternates**:

- **AB**: Task 1 Baseline · Scenario A → Task 2 MacroTable · Scenario B
- **BA**: Task 1 MacroTable · Scenario A → Task 2 Baseline · Scenario B

Pilot participants are `VT001–VT006`; main-study participants are `VP001–VP040`. Assign codes strictly in order. If a participant drops out, don't reuse the code; note it and continue. All links are in [`assignment-schedule.csv`](assignment-schedule.csv).

> If the team changes scenarios or the design at freeze, regenerate this file rather than hand-editing links.
